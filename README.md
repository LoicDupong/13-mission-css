## 📚 Contexte pédagogique

Ce projet a été réalisé dans le cadre d’une formation JavaScript FullStack.  
L'objectif de ce défi est de manipuler des propriétés CSS avancées pour créer une carte interactive 100% CSS, sans JS.

---

## 🧪 Propriétés CSS non vues en cours

Voici les propriétés utilisées dans ce projet qui n’ont pas encore été abordées pendant la formation :

| Propriété | Rôle |
|-----------|------|
| `perspective: 500px;` | Définit la profondeur de vue 3D pour un effet de rotation réaliste sur l’élément enfant. |
| `transform-style: preserve-3d;` | Permet à l'élément de conserver la perspective 3D pour ses enfants. |
| `backface-visibility: hidden;` | Cache l'arrière d’un élément lorsque celui-ci est retourné. |
| `transform: rotateY(180deg);` | Applique une rotation de 180° sur l’axe Y pour créer l’effet de retournement. |

Ces propriétés fonctionnent ensemble pour rendre l’animation de flip fluide et crédible visuellement.
